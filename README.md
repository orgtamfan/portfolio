# Portfolio

Responsive personal portfolio for Olan Siallagan, built with Vite and vanilla JavaScript.

## Run locally

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

## Update content

- Edit `index.html` for page copy and layout.
- Edit the project data and interactions in `main.js`.
- Edit the design tokens and responsive styles in `src/style.css`.
